# Second Hand Goods Exchange Platform

A simple web application where users can browse and search for second-hand items to exchange.

## Features
* **User Login:** Basic login authentication to access the platform.
* **Item Listings:** Displays available second-hand goods with short descriptions.
* **Live Search:** Filter items in real-time by typing in the search bar.
* **Navigation:** Basic menu structure for Home, Orders, Adding Items, Account, and Logout.

## Technologies Used
* HTML
* CSS
* JavaScript
